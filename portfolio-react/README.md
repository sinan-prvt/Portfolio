# Mohamed Sinan — Portfolio

Single-page portfolio built with plain HTML, CSS and JavaScript, with Three.js (3D scenes), Matter.js (physics), GSAP + ScrollTrigger and Lenis (smooth scroll) loaded from CDNs.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

Everything lives in `index.html`. Images, the CV and other static files are in `public/`.
